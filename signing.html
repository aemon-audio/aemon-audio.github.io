Code signing and privacy

How a release is made

Every release is built by GitHub’s own computers, directly from the public source code. The same run executes the audio tests and the plugin host tests. Nobody builds a release on a private machine.

Signing

The first releases aren’t signed yet, and signing is coming soon. We’ll apply for free open-source code signing as soon as the code is public. This page will name the certificate and the people who approve releases when that’s in place. Until then Windows shows two warnings. This is what they mean and what to press.

Until then, you can check that your download is the real one. Each release lists the SHA-256 checksum of its files. In PowerShell:

Get-FileHash .\Aemon-Suite-Setup.exe

Privacy

The plugins don’t connect to the internet. They collect nothing and send nothing. The only files they write are presets you save, in Documents\Aemon, and what your DAW stores in your projects.

This website has no cookies, no analytics and no third-party scripts. It’s hosted by GitHub Pages, and GitHub may log visitors’ IP addresses for security, as any host does.
